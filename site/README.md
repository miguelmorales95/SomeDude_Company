# somedude.app

The company site for SomeDude: a static page (HTML + CSS, no build step) introducing Kinmap,
Afoot and NoBucks, plus `privacy.html` (somedude.app/privacy, which links to each app's own policy).
Styles follow `Company-Design-System.md` in this repository.

Deploy: a Vercel project importing this repository with Root Directory `site` (framework "Other",
no build command), with the domains `somedude.app` and `www.somedude.app`.
